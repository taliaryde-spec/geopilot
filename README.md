# GeoPilot

GeoPilot 是一个自然语言驱动的地理空间分析 Agent。用户提供空间数据和分析问题，Agent 自动检查数据、规划分析步骤、调用 GIS 工具、验证结果并生成地图和报告。

## 核心用户故事

作为一名 GIS 分析人员，我希望用自然语言描述空间分析任务，让 Agent 生成并执行可检查、可复现的分析流程。

## MVP 功能

* 读取 GeoJSON 和带经纬度的 CSV
* 检查字段、几何类型、缺失值和坐标参考系统
* 将自然语言问题转换为空间分析计划
* 在执行分析前让用户确认计划
* 执行投影转换、缓冲区和空间连接
* 验证距离单位、空值和结果数量
* 输出结果数据与 Markdown 分析报告

## 演示场景

分析居民区附近的公共服务设施覆盖情况，找出服务不足的区域，并生成分析结果和选址建议。

## v0.1 暂不实现

* 栅格和遥感影像分析
* QGIS 插件
* PostGIS
* 多 Agent 并行工作流
* 云端部署

## v0.1 验收标准

- 系统能够读取一个 GeoJSON 面图层和一个带经纬度字段的 CSV 点图层
- 系统能够输出数据字段、记录数量、几何类型、CRS 和缺失值统计
- 进行距离分析前，系统必须将地理坐标系转换为使用米作为单位的投影坐标系
- Agent 必须先生成包含输入、步骤、输出和风险的分析计划，获得用户确认后才能执行
- 系统能够完成缓冲区和空间连接，并输出 GeoJSON 结果与 Markdown 报告
- 报告必须包含使用的 CRS、距离单位、匹配数量、未匹配数量和空值比例
- 当输入数据缺少 CRS、经纬度字段或包含无效几何时，系统必须明确报错，不能编造结果
